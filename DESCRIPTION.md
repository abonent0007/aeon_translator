🌌 AEON v3.0 — Универсальный Транслятор Смысла
================================================

AEON — это семантический процессор нового поколения. Вместо перевода слов
он переводит СМЫСЛ. Извлекает чистое значение из любой формы (текст, код,
эмоция, голос) и перевыражает его в любой другой форме.

ВОЗМОЖНОСТИ:
  • Перевод смысла между 50+ языками (DeepSeek LLM)
  • Кодогенерация: описание → Python/JavaScript
  • Мост разумов: сравнение смысла высказываний (LaBSE + LLM)
  • Голос: распознавание (Whisper) + синтез речи (ru/en/zh)
  • Генерация изображений (Flux 2)
  • Верификация: защита от галлюцинаций
  • Интерпретируемость: цепочки рассуждений, сущности, роли
  • .aeon — бинарный формат смысла (2.2 КБ/атом, в 1000× компактнее LLM)
  • Веб-интерфейс на 3 языках (ru/en/zh) с нейро-облаком
  • CLI + Python API

УСТАНОВКА:
  1. Клонировать репозиторий
  2. Запустить install.ps1 (Windows) или pip install -r requirements.txt
  3. Создать .env из .env.example, добавить API-ключи
  4. python -m aeon.web_server → http://localhost:8080

ТРЕБОВАНИЯ: Python 3.8+, ~3 ГБ места

🌌 AEON v3.0 — Universal Meaning Translator
================================================

AEON is a next-generation semantic processor. Instead of translating words,
it translates MEANING. It extracts pure significance from any form (text,
code, emotion, voice) and re-expresses it in any other form.

FEATURES:
  • Meaning translation across 50+ languages (DeepSeek LLM)
  • Code generation: description → Python/JavaScript
  • Bridge of minds: semantic similarity (LaBSE + LLM, 3 methods)
  • Voice: speech recognition (Whisper) + synthesis (ru/en/zh)
  • Image generation (Flux 2)
  • Anti-hallucination verification (consistency + fact grounding)
  • Full interpretability: reasoning chains, entities, roles, evidence
  • .aeon — binary meaning format (2.2 KB/atom, 1000× smaller than LLM weights)
  • Web interface in 3 languages (ru/en/zh) with neural cloud animation
  • CLI + Python API

INSTALLATION:
  1. Clone the repository
  2. Run install.ps1 (Windows) or pip install -r requirements.txt
  3. Copy .env.example to .env, add your API keys
  4. python -m aeon.web_server → http://localhost:8080

REQUIREMENTS: Python 3.8+, ~3 GB disk space

"Meaning is one. Only the forms differ."


🌌 AEON v3.0 — 通用意义翻译器
================================================

AEON 是下一代语义处理器。它不翻译词语，而是翻译意义。
从任何形式（文本、代码、情感、语音）中提取纯粹的含义，
并以任何其他形式重新表达。

功能：
  • 50+ 种语言的意义翻译 (DeepSeek LLM)
  • 代码生成：描述 → Python/JavaScript
  • 思维桥梁：语义相似度比较 (LaBSE + LLM，3种方法)
  • 语音：识别 (Whisper) + 合成 (ru/en/zh)
  • 图像生成 (Flux 2)
  • 反幻觉验证（一致性 + 事实依据）
  • 完全可解释性：推理链、实体、角色、证据
  • .aeon — 二进制意义格式 (2.2 KB/原子，比LLM权重小1000倍)
  • 三语言网页界面 (ru/en/zh) 带神经元云动画
  • CLI + Python API

安装：
  1. 克隆仓库
  2. 运行 install.ps1 (Windows) 或 pip install -r requirements.txt
  3. 从 .env.example 复制到 .env，添加 API 密钥
  4. python -m aeon.web_server → http://localhost:8080

要求：Python 3.8+，约 3 GB 磁盘空间

"意义是统一的。不同的只是形式。"
