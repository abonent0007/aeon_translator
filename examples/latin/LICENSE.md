# Лицензии и атрибуция — examples/latin/

Короткие УЧЕБНЫЕ фрагменты для демонстрации LOGOS.

- **Древние латинские тексты** (Caesar, Cicero, Vergil, Vulgata):
  авторы античности/поздней античности — общественное достояние
  (public domain).
- **Транскрипции** — собственные, с макронами (учебная конвенция LOGOS);
  **не копии** набора конкретных изданий (OCT/Teubner/Loeb — сам набор
  и критический аппарат могут охраняться авторским правом).
- **Надпись** (`inscription_cil_lacunae.txt`) — педагогический образец
  конвенций CIL; копии конкретных записей CIL/EDCS не выполнялись
  (лицензии EDCS не проверялись — стоп-точка 2.2 №4).
- **Макроны в Vulgata** добавлены LOGOS для учебных целей — традиционный
  набор Vulgata их не содержит (отличие от Caesar/Cicero/Vergil, где
  макроны — учебная транскрипционная конвенция).

План (Ф2.6): offline-адаптеры корпусов с per-file лицензиями и атрибуцией.
